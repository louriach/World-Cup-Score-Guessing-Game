Golden Goals

Predict every World Cup 2026 score. Beat your mates.

Golden Goals is a free score prediction game for the FIFA World Cup 2026. Predict match scores, earn points, and compete in private leagues with friends.

How it works

  • Predict the score of every match before kick-off
  • Earn 3 points for an exact score, 1 point for the correct result
  • Create or join private leagues with friends using a code and phrase
  • Get push notifications for match reminders and results
